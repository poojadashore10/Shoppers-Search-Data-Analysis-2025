# Shoppers Search Data Analysis 2025 (Excel Project)

## Overview

This project is an Excel-based data analysis and interactive dashboard project created using shopping sales data from the **Shoppers Search** platform.

The analysis focuses on:

* Customer purchasing behavior
* Sales trends
* Gender-wise analysis
* Age-group segmentation
* Sales channel performance
* Order tracking insights

The project demonstrates practical business analytics skills using Microsoft Excel.

---

# Objective

The objective of this project is to:

* Analyze shopping sales data
* Identify customer behavior patterns
* Track monthly sales trends
* Compare platform/channel performance
* Create an interactive business dashboard
* Generate actionable business insights

---

# Dataset Information

The dataset contains shopping transaction data ,including:

* Order ID
* Customer ID
* Gender
* Age
* Age Group
* Order Date
* Month
* Sales Channel
* Order Status
* Sales Amount

The data was cleaned, transformed, and analyzed using Microsoft Excel.

# Analysis Performed

## 1. Gender-wise Sales Analysis

Analyzed purchasing contribution by male and female customers.

## 2. Age Group Analysis

Compared sales among:

* Adults
* Teenagers
* Seniors

## 3. Monthly Sales Trend Analysis

Tracked sales performance across months to identify peak shopping periods.

## 4. Sales Channel Analysis

Compared performance across platforms such as:

* Amazon
* Myntra
* Ajio
* Other shopping channels

## 5. Order Status Analysis

Analyzed order completion and delivery patterns.
